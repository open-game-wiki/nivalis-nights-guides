# Nivalis Nights Wiki

Independent bilingual guide site for Nivalis Nights. Content sources reviewed on **2026-10-13**; this is an editorial review date, not a claim of an in-game test.

## Content policy

- Keep official facts, editorial suggestions and measured observations distinct.
- Cite a source for a numerical game claim, including its version and scope. A general feature description does not prove prices, probabilities, rewards or unlock conditions.
- Do not publish complete-list titles until the listed records are complete and checked.
- Original publication dates are retained; `reviewDate` tracks the latest source review.
- Illustrations are not evidence of a mechanic. Do not attach official screenshot or benchmark labels without provenance.

## Tools and routes

Existing English and Chinese routes remain available. Budget and harvest worksheets use user-entered observations without game presets. The catch notebook starts empty; it is not a species database. None of these tools predicts hidden mechanics.

## Maintenance

This repository contains the public Markdown guide copies. The separate site repository uses Astro 4 and Tailwind CSS. Guide Markdown in `src/content/guides/` is mirrored to the separate `nivalis-nights-guides/guides/` repository, including its `zh/` directory. Keep both copies identical.

No deployment or publication is implied by a local content change.
