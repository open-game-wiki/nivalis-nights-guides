## 🤝 Contributing to Game Guides

Found a typo, an outdated ingredient procurement cost, or a patch adjustment in fish bite rates? Community contributions to the documentation are warmly welcomed:

1. Fork this repository: `https://github.com/open-game-wiki/nivalis-nights-guides`
2. Create your fix branch: `git checkout -b fix/tonkotsu-recipe-price`
3. Edit the relevant Markdown file in `./guides/` (and `./guides/zh/` if applicable).
4. Commit your changes: `git commit -m "fix(recipes): update Tonkotsu pork bone cost after Patch 1.1"`
5. Push to your branch and open a Pull Request.
