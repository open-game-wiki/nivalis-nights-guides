## Does Nivalis Nights have official modding tools?
The developer FAQ says modding tools are outside the game's current scope. This is different from claiming that no community modifications exist. This page does not provide a verified mod catalogue, an official mod loader or a tested installation folder.

## Before downloading a community mod
Check the exact game title and supported build, author, dependencies, installation method and removal instructions. A mod for Cloudpunk, a similarly named game or an earlier Nivalis build is not automatically compatible. If a mod page omits its supported version or recovery steps, compatibility remains unknown.

## Back up saves first
The official Windows support post places `.sav` files and game logs under:

```text
%USERPROFILE%\AppData\LocalLow\ION LANDS\Nivalis Nights
```

Close the game and keep a separate copy of your saves before changing files. Label the copy with the game build and date. These are editorial backup precautions; Steam Cloud synchronization is not a versioned backup of your preferred save.

## Try one change at a time
Keep the author's instructions and original files. Apply only one change, check whether the game loads and whether your intended action works, and record the result. If something breaks, stop adding mods and follow that author's removal steps. File verification may restore game files, but does not prove that every third-party file has been removed.

## Report a reproducible issue
Compare the problem with an unmodified session where possible. Record the game build, mod versions and reproduction steps. Capture logs before launching again, because the official support post warns that launches replace earlier logs. Use the developer's support link for game issues.
